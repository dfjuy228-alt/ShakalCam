# ShakalCam — Android / Xiaomi

Демонстраційний Android-проєкт: камера в реальному часі з навмисно низькою якістю.

## Що робить
- показує відео з камери в окремому застосунку;
- знижує деталізацію, додає шум і кольорові смуги;
- повторно стискає кадри JPEG для артефактів;
- дозволяє зберегти поточний оброблений кадр у `Pictures/ShakalCam`;
- перемикає передню/задню камеру.

Це прототип із вихідним кодом, а не вже зібраний і перевірений APK. Я не можу підтвердити роботу на конкретній моделі Xiaomi без тестування на пристрої.

## Збірка APK
1. На ПК встанови Android Studio з офіційного сайту Android Developers.
2. Розпакуй архів `ShakalCam-source.zip`.
3. В Android Studio обери **Open** і відкрий папку `ShakalCam`.
4. Дочекайся Gradle Sync. Якщо Android Studio запропонує встановити Android SDK 35 або компоненти Build Tools, погодься.
5. Обери **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. Після успішної збірки натисни **locate** у сповіщенні. Зазвичай APK лежить у `app/build/outputs/apk/debug/app-debug.apk`.
7. Передай APK на Xiaomi, відкрий файл і дозволь встановлення з цього джерела, якщо Android запитає.
8. Запусти ShakalCam і надай дозвіл на камеру.

## Важливі обмеження
- У проєкті немає системної підміни камери. Звичайні Android-застосунки не можуть універсально підміняти камеру для всіх інших застосунків.
- Для відеодзвінків у Meet/Zoom/месенджерах ефект не з'явиться автоматично. Зазвичай треба, щоб сам сервіс підтримував віртуальне джерело або ефекти камери.
- Поточна версія зберігає оброблене фото, а не записує оброблене відео.
- Цільова картинка навмисно дуже низької якості; на різних моделях може відрізнятися FPS і доступна роздільність.
- Для повноцінної версії бажано протестувати конвертацію YUV на конкретному пристрої та профілювати навантаження.

## Технології
Kotlin, CameraX, Android SDK 35, minSdk 26.

# Как получить APK без компьютера

В этом архиве есть исходный проект и файл автоматической сборки `.github/workflows/build-apk.yml`. Сборка выполняется на серверах GitHub, а не на телефоне. Нужен аккаунт GitHub и интернет. APK будет отладочным (debug), не опубликованным в магазине.

## Самый короткий путь с телефона
1. Откройте в браузере https://github.com и войдите/создайте аккаунт.
2. Нажмите `+` → `New repository`. Назовите репозиторий `ShakalCam`, выберите `Public` или `Private`, затем `Create repository`.
3. На странице нового репозитория выберите `Add file` → `Upload files`.
4. Сначала распакуйте ZIP в файловом менеджере телефона. Загрузите содержимое папки `ShakalCam` в корень репозитория, включая скрытую папку `.github`. Если мобильный сайт не показывает скрытые файлы или не даёт загрузить папку, этот способ может потребовать ПК.
5. Нажмите `Commit changes`.
6. Откройте вкладку `Actions` → workflow `Build ShakalCam APK` → `Run workflow`, если сборка не стартовала автоматически после загрузки.
7. Когда запуск станет зелёным, откройте его, пролистайте до `Artifacts` и скачайте `ShakalCam-debug-apk`.
8. Распакуйте скачанный артефакт на телефоне. Внутри будет `app-debug.apk`. Откройте APK и, если Android спросит, разрешите установку из этого источника.

## Важно
- Я добавил автоматическую конфигурацию сборки, но не могу подтвердить, что проект компилируется, пока сборка не будет реально запущена. Если GitHub покажет красный крестик, откройте лог и пришлите сюда скриншот ошибки.
- APK пока не подписан для публикации в Google Play; это тестовая сборка для установки вручную.
- Приложение предназначено для тестирования своей камеры. Этот проект не подменяет камеру глобально в других приложениях и не добавляет запись видео.
